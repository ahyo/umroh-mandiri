# Panduan Umroh Mandiri

Situs statis berisi panduan umroh mandiri dari Indonesia: syarat (UU 14/2025), pesan hotel & visa lewat Nusuk, tiket pesawat, rute Madinah → Bir Ali → Makkah → Jeddah, tata cara umroh beserta doa, kalkulator biaya, dan checklist.

Dibuat dengan HTML, CSS, dan JavaScript biasa tanpa build step, lalu di-deploy lewat GitHub Pages.

Jalankan secara lokal: buka `index.html` di browser.
